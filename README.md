# New Quick Sort

## Como rodar

Requisito: Java (JDK 8 ou superior) instalado.

### Pelo terminal

Na raiz do projeto:

```bash
javac -d out src/QuickSort.java
java -cp out QuickSort
```

Saída esperada:

```
Recursivo: [1, 2, 3, 4, 5, 6, 7, 8]
Iterativo: [1, 2, 3, 4, 5, 6, 7, 8]
```

### Pelo IntelliJ IDEA

1. Abra a pasta do projeto no IntelliJ.
2. Abra `src/QuickSort.java`.
3. Clique no botão ▶ ao lado do método `main` e escolha **Run 'QuickSort.main()'**.
